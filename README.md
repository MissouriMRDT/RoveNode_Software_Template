# RoveNode_Software_Template
Pre-generated STM32CubeIDE project template for developing on RoveNode hardware.

**Note:** Please refer to the [STM32 CubeMX Configuration Guide](https://mailmissouri.sharepoint.com/:w:/r/sites/SDELC-MarsRoverDesignTeam-Ogrp/_layouts/15/Doc.aspx?sourcedoc=%7BD44263E7-B9E8-451B-91D2-369557EAB64A%7D&file=STM32%20CubeMX%20Configuration.docx&action=default&mobileredirect=true) to reference STM feature configuration.

CubeMX is intended to be used only as a reference and should **not** overwrite the template! Configure your project using the RoveOS submodule included in this template instead.
You can create a fork of this repository on GitHub to build off of this template for your project.
